# Launchpad — Quick Start

Get up and running in under 2 minutes.

## 1️⃣ Install
```bash
git clone https://github.com/Peter-Pix/launchpad.git
cd launchpad
npm install
```

## 2️⃣ Run
```bash
npm run dev
```

## 3️⃣ Use
Open [http://localhost:3005](http://localhost:3005) in your browser.

### First Time Setup
- Launchpad automatically scans `~/projects` for apps
- To change the folder: click ⚙️ → enter path → Save
- Apps appear as cards — click ▶ to start, ⎇ to view logs

### Common Actions
- **Start/Stop app**: Click ▶/✕ on app card
- **View logs**: Click ⎇ on app card
- **Search apps**: Press `Ctrl+K` and type
- **Change language**: Click 🇬🇧/🇨🇿 in header
- **Open in browser**: Click 🔗 on app card (if URL detected)
- **Refresh list**: Click ↻ in header

### Tips
- `Esc` closes search/settings/logs
- Hover over status dots for tooltips
- Long commit hashes show full hash on hover
- Workspace buttons (⚡) start/stop groups of apps
- Footer shows scan path and helpful reminders
